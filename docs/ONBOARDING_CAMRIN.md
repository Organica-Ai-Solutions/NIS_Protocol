## ⚡ Quick Start (5 min)

### 1. Clone the main repo
```bash
git clone https://github.com/organica-ai/NIS_Protocol.git
cd NIS_Protocol
```

### 2. Set up Python environment
```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 3. Run the backend
```bash
uvicorn main:app --reload
```

### 4. Open the API docs
```
http://localhost:8000/docs
```
